# Tarek Ragab — Portfolio

A responsive static portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive dark cloud/security design
- `script.js` — mobile navigation

## Deploy with GitHub Pages
1. Create a GitHub repository (for example: `portfolio`).
2. Upload these three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the live website URL.

The project section intentionally does not contain a GitHub repository link because the project is not publicly uploaded.
